# Arah Plan M: Tenang palette on CoMaps (port table)

Generated by Plan M Task 2. Every colour variable in CoMaps' `default` and `vehicle` palettes, and every
outdoors override, got exactly one rule. Variables not listed here are `unchanged`: Arah left them at the
upstream value on Organic Maps too, so they keep CoMaps' value.

Rules:
- **arah**: Arah changed this colour on Organic Maps (Plans 1 and its fixes) and CoMaps still has it: Arah's value.
- **bg**: CoMaps split `@background` into `@background0`/`@background1`: both get Arah's background
  (the map background is read from `natural-land`, i.e. `@background1` at z16+).
- **river**: CoMaps draws rivers with `@water`; Arah restores `@river` (one rule in `default/include/Basemap.mapcss`)
  so rivers stay visible at night, as on Organic Maps.
- **border**: road casings added by CoMaps: Tenang fill + CoMaps' fill-to-casing offset (Lab).
- **relative**: motorways keep CoMaps' offset from trunk roads; residential gardens from the background;
  playgrounds from parks; wetlands from water (Lab).
- **role veg**: CoMaps' new greens (park, grass, woods, …): matched by lightness to the Organic Maps green Arah
  changed, shifted by the same lightness, with Tenang's mint hue.
- **role** (other): CoMaps value + (Arah − Organic Maps) of the nearest Organic Maps colour Arah changed in the same
  role group (landuse, building, bridge, labels), in Lab.
- **outdoors**: outdoors overrides of a Tenang default colour keep their offset from the default.
- **keep**: left at CoMaps' value, with the reason.
- **night labels** (final review fix): the neutral label greys in both dark palettes are lifted by 8 L* so road
  names stay readable on Tenang's lighter night background (pinned by `Arah_DarkRoadNamesReadable`).
- **duplicates**: vehicle palettes define `@water_label` twice (CoMaps added a second label block); kothic keeps
  the last definition, so both get the Tenang value (pinned by `Arah_VehicleWaterLabels`).
- Outdoors map modes re-declare the river rule in `outdoors/include/Basemap.mapcss`; it uses `@river` too.
